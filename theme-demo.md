# Jekyll theme demo

This page exists only to prove the theme works. It is **not** part of the SMELLTEST site.

Everything below this line is styled by `jekyll-theme-hacker`, which GitHub Pages
loaded because of two things:

1. `_config.yml` contains `theme: jekyll-theme-hacker`
2. This file starts with front matter containing `layout: default`

Your other pages have no front matter, so Jekyll copies them through untouched.

## A table

| Item | Value |
| --- | --- |
| Theme | jekyll-theme-hacker |
| Renderer | Jekyll (GitHub Pages built-in) |
| Layout | `default` |
