01 · Reading the tree

What the DOM is

When a browser loads an HTML file it does not keep the text as a flat string. It parses the markup into a tree of objects — the Document Object Model. Every element becomes a node, nested inside its parent. JavaScript then reaches into that tree (with document.querySelector) to add, remove or restyle things, which is exactly how this site's filters, countdown and forms work.

02 · What differs per page

Six pages, one skeleton

Requirement #3 asks for a consistent link structure. That consistency is enforced structurally: the header, nav, marquee and footer blocks are byte-for-byte identical, and only main is swapped.

File Contents of main JavaScript feature
index.html hero, featured fragrances, house story, animated stats, CTA Count-up stats on scroll
products.html category filters, 8 fragrance cards, quick-view modal, add to bag Filtering, modal, shopping bag + localStorage
trustees.html 5 trustee cards with portraits and expandable profiles Profile expand/collapse
events.html live countdown, upcoming events, archive Real-time countdown timer
contact.html booking form, inquiry form, saved requests, FAQ Validation + localStorage + accordion

03 · The shared nodes

Why the tree is shaped this way

  • 01

    header → nav → ul → li → a

    A list of links, not a row of divs. Screen readers announce “navigation, list, 5 items”, and the same five links appear in the same order on every page.

  • 02

    main is a single landmark

    One main per document, so the skip link can jump straight past the repeated chrome. Search engines also use it to distinguish page content from boilerplate.

  • 03

    section per topic, each with a heading

    Sections map to the outline of the page. No section is left without an h2, so the document outline stays readable when styles are turned off.

  • 04

    data-* attributes carry the data

    Product cards hold their name, price, notes and availability in data- attributes. JavaScript reads them to build the modal — no duplication of content in the script.
